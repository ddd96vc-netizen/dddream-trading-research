# 🧪 Sandbox

Aquí van los scripts de un solo uso o circunstanciales: arreglar algo puntual,
probar una idea rápida, un experimento de una tarde. Cosas "cacharreadas".

## La regla

Cualquier archivo que aparezca aquí tiene dos destinos posibles, nunca se
queda para siempre:

1. **Se borra** — cumplió su propósito puntual (reparar un dato, probar
   algo que no llevó a ningún lado) y ya no hace falta.
2. **Se promueve** — si demuestra que vale la pena mantenerlo, se mueve a
   `scripts/` (si es una utilidad de mantenimiento) o a `research/` (si es
   un hallazgo o una validación real), con su nombre y carpeta definitivos.

## Por qué existe esta carpeta

Para no ensuciar `research/` y `scripts/` con pruebas a medio hacer, pero
sin perder la costumbre de resolver las cosas rápido con un script suelto
en vez de complicarse con una interfaz web para todo.

*(Esta carpeta puede estar vacía en el repo — eso es lo esperado. Los
archivos que pasen por aquí en tu máquina local no tienen por qué subirse
a GitHub salvo que decidas promoverlos.)*
